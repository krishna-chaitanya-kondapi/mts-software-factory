# Documentation Engineering skill
1. Discover root AGENTS.md and governing strategy; read [standard](../../strategy/documentation-engineering/DOCUMENTATION-STANDARD.md) and [rubric](../../strategy/documentation-engineering/documentation-rubric.yaml). Record versions and source revision; proposed guidance applies to authorized pilots only until ratified.
2. Resolve audience, purpose, document type, review scope/depth/perspective where relevant, baseline and authority. Invoke [Reviewability Engineering](../reviewability-engineering/SKILL.md) for review artifacts; reuse existing taxonomy and canonical visuals.
3. Establish concise holistic overview, navigable detail, first-principles language, comparison tables, implementation examples and meaningful mental models. Preserve authoritative meaning and trace metadata.
4. Use one composite verification report with applicable RE and DE criteria, evidence, exceptions and unknowns. Correct within bounded budget, recheck changed content, escalate unresolved issues. Never claim unperformed checks.
5. Persist candidate revisions as drafts, read back exact revision, check links and visual fidelity using RE rules. Human approval binds exact revision; no implicit approval or release. Record proposed deltas for future evolution.
