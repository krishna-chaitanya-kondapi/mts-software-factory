# MTS Software Factory

A reusable, model-agnostic, AI-native software factory, with MTS educational products as the first implementation domain—not the architectural boundary.

## Engineering method

M0–M8 stations connect intent and ontology, business architecture, requirements and verification criteria, solution architecture, executable design, modular build, independent evidence, human acceptance, and outcome learning. A bounded convergence controller routes defects and gaps back to the responsible station. Human authority, atomic IDs and persistent traceability govern every loop.

## Bootstrap status

**In progress (2026-11-06).** Canonical strategy is present and revised. A limited assessment MCQ quality implementation and test already exist; this is not complete factory automation. Station templates are proposed scaffolds, not proof of M0–M8 orchestration or autonomous convergence. No full permanent directory architecture has been approved.

Architecture rationalization will be proposed on a review branch. Draft recommendations are not accepted decisions.
