# MTS Software Factory

A reusable, model-agnostic, AI-native software factory, with MTS educational products as the first implementation domain—not the architectural boundary.

## Engineering method

M0–M8 stations connect intent, requirements, architecture, design, implementation, verification, delivery, observation, and learning. Human authority, atomic artifact IDs, traceability, evidence gates, and requirement-delta feedback are fundamental.
